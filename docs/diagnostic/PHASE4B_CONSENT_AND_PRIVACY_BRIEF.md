# Tooltrim — Cadrage consentement Phase 4B

> Statut : texte de cadrage bêta
> Périmètre : sessions privées Créatif

## 1. Version courte à lire au début

Avant de commencer :

- la session sert à tester Tooltrim, pas à évaluer ton travail ;
- tu peux arrêter à tout moment ;
- tu peux refuser de montrer certains outils, prix ou clients ;
- les notes serviront à améliorer le produit ;
- si un enregistrement est demandé, il nécessite ton accord explicite ;
- les exemples partagés seront anonymisés dans les documents internes ;
- tu peux demander la suppression de tes notes après la session.

Question :

> Est-ce que tu es d’accord pour continuer dans ces conditions ?

Réponse :

- oui / non ;
- enregistrement autorisé : oui / non ;
- citation anonymisée autorisée : oui / non.

## 2. Version écrite à envoyer

Merci de participer à la bêta privée Tooltrim.

Pendant la session, nous allons observer comment tu utilises Tooltrim pour cartographier ta vraie stack créative. Les informations discutées peuvent inclure des outils, usages, contrats, budgets approximatifs ou habitudes de travail.

Nous utiliserons ces informations uniquement pour améliorer le produit.

Tu peux :

- masquer une information sensible ;
- répondre “je ne sais pas” ;
- arrêter la session ;
- refuser l’enregistrement ;
- demander l’anonymisation ou la suppression de tes notes.

Nous ne publierons pas ton nom, tes clients, tes prix ou ta stack identifiable sans accord explicite.

## 3. Ce qu’il ne faut pas demander

Ne pas demander :

- mots de passe ;
- accès aux comptes ;
- documents clients confidentiels ;
- factures nominatives ;
- données personnelles de clients ;
- informations financières précises non nécessaires.

Si l’utilisateur veut montrer un contrat, lui proposer plutôt de résumer :

- payeur ;
- ordre de grandeur ;
- outil couvert ;
- incertitude éventuelle.

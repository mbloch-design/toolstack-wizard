## 3. Après chaque session

À faire dans les 15 minutes :

1. Copier les notes dans `PHASE4_OBSERVATION_GRID.md` ou une fiche dédiée.
2. Ajouter une entrée réelle dans `PHASE4_BETA_SESSIONS.json`.
3. Classer chaque problème P0/P1/P2/P3.
4. Lancer `npm run assess:g4`.
5. Décider : continuer la vague, corriger P0/P1, ou suspendre.

## 4. Règle de correction vague 1

- P0 reproductible : corriger avant toute nouvelle session.
- P1 reproductible : corriger avant d’élargir la vague.
- P2 isolé : noter, attendre répétition.
- P3 : backlog, ne pas interrompre.

## 5. Synthèse à produire après 6 sessions

Créer une synthèse avec :

- taux de complétion ;
- temps médian pré-verdict ;
- taux diagnostic actionnable ;
- fidélité cartographie ;
- questions répétitives ;
- confusion capture/recommandation ;
- P0/P1 ouverts ;
- recommandations de correction avant vague 2.

# GO67 — Restitution des recommandations créatives

## But

Faire en sorte qu'une recommandation créative raconte un manque de workflow précis, au lieu d'afficher seulement un nom d'outil avec une justification générique.

## Ce qui change

- une recommandation créative hérite d'une raison métier claire
- la raison mentionne le maillon manquant du workflow
- quand c'est pertinent, la raison cite le contexte déjà présent dans la stack
- la même narration est utilisée :
  - dans les cartes de recommandations
  - dans le plan d'action différé

## Exemples

- `Figma Tokens` n'arrive pas comme "outil design en plus" mais pour `fiabiliser le système design`
- `Frame.io` n'arrive pas comme "outil vidéo utile" mais pour `fluidifier la review vidéo`
- `Brevo` n'arrive pas comme "outil marketing" mais pour `relier contenu et conversion`

## Impact produit

Le rapport final commence à ressembler à une lecture d'expert métier :

- ce que tu as déjà
- ce qui manque entre deux maillons
- pourquoi cet outil est proposé maintenant
- pourquoi ce n'est pas juste un ajout arbitraire de plus

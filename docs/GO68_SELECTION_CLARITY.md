# GO68 — Clarté d’ajout d’un outil

## But

Rendre l’interaction d’ajout d’outil immédiatement compréhensible :

1. je choisis un outil
2. je choisis son mode / plan
3. il rejoint ma stack

## Correctifs

- ajout d’un repère visuel `1 / 2 / 3` en haut de l’écran
- message contextuel quand un outil est en attente de confirmation
- cartes outil plus explicites sur ce que déclenche le premier clic
- blocage doux du CTA `Zone suivante` tant qu’un outil est à moitié sélectionné
- recentrage automatique sur la carte active au moment du choix du mode

## Impact UX

Le flow devient plus lisible sans ajouter de complexité :

- moins d’hésitation au premier clic
- moins de confusion sur l’endroit où choisir le mode
- meilleure continuité entre la grille de gauche et la stack de droite

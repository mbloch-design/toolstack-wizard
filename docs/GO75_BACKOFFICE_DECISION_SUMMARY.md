# GO75 - Résumé décisionnel back-office

## Problème traité

Le back-office enregistrait les données détaillées, mais demandait encore de
reconstruire la conclusion de la session à partir du score, des prescriptions et
des recommandations.

## Décisions

Le contexte final enregistre :

- le nombre d'actions immédiates, à vérifier et différées ;
- le nombre de recommandations ;
- la première décision proposée ;
- les trois premières pistes associées ;
- le nombre d'outils et de plans dont le prix reste à préciser.

Le détail de session affiche ce résumé dans un bloc dédié.

## Critère de réussite

Une personne en back-office comprend l'intention de suivi d'une session en moins
de trente secondes, sans ouvrir toutes les annexes.

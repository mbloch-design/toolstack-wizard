## Composant commun

`ComparisonMedia` consomme les médias du Tool publié, déduplique les URL, ignore les couvertures bloquées, retire les images en erreur et conserve un cadre de mêmes dimensions. Le repli est une illustration explicitement nommée. Les médias ne sont pas présentés comme des captures testées. Les textes FR/EN restent hors des images ; les textes incorporés aux médias existants conservent leur langue originale.

Les critères et décisions continuent de venir des données éditoriales existantes. Le filtre affiche tous les critères par défaut. Le mouvement est désactivé avec prefers-reduced-motion.

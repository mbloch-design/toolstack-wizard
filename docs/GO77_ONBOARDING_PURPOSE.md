# GO77 - Recentrage de l'onboarding

## Décision produit

L'ancien écran de personnalisation est supprimé.

Il regroupait trois intentions incompatibles :

- personnaliser le ton avec un prénom ;
- collecter un email avant la création du rapport ;
- demander un tarif jour pour un calcul secondaire.

Ces informations n'améliorent pas la capture de stack et créent une rupture juste
avant le coeur du produit.

## Nouveau parcours

Profil → spécialité créative éventuelle → priorité → ajout des outils.

L'email reste proposé quand le rapport est prêt, avec une promesse concrète :
recevoir une copie. Le diagnostic principal fonctionne sans prénom et sans tarif
jour.

## Effet attendu

- une étape en moins ;
- aucune collecte prématurée ;
- un CTA qui annonce exactement l'écran suivant ;
- une transition immédiate vers la tâche attendue.

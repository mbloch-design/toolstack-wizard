# GO66 - Creative Gap Recommendations

## Goal

GO66 makes recommendations feel less like a generic catalog and more like a missing-link engine for creative workflows.

## What changes

- Each creative specialty now exposes missing adjacent tool families.
- Recommendations can prioritize tools that fill a concrete workflow gap:
  - UI handoff
  - brand-system assets
  - motion review and plugins
  - photo delivery and presets
  - content distribution and measurement
  - illustration / 3D pipeline continuity
  - creative ops follow-through
- Those missing-link recommendations can outrank otherwise higher-scoring generic suggestions.

## Why it matters

For a creative stack, the next useful tool is often not "the best tool in the catalog". It is the tool that closes the next missing step in the workflow.

## Validation

`npm run validate:go66`

# GO74 - Preuves des recommandations créatives

## Problème traité

Une recommandation de plugin, ressource ou outil périphérique peut sembler arbitraire
si elle ne montre pas le lien avec la stack déjà captée.

## Décisions

Chaque recommandation expose désormais quatre niveaux :

1. Le rôle métier du nouvel outil.
2. Le bénéfice attendu dans le workflow.
3. Le maillon qu'il vient compléter.
4. Le déclencheur observé dans la stack actuelle.

Le rapport distingue explicitement un outil complémentaire d'un remplacement.

## Critère de réussite

Un créatif doit pouvoir répondre à ces trois questions sans interprétation :
pourquoi cet outil, pourquoi maintenant, et avec quel outil déjà présent.
